How to Use This System

1. Select your department from the dropdown menu

2. Enter the patient's UHID (Unique Hospital ID)

3. Choose the priority level (Routine, Urgent, or STAT)

4. Select the specimen type (Blood, Urine, Tissue, etc.)

5. Add clinical notes if needed

6. Check the tests you want from the available categories

7. Submit the request - the system will automatically check for results
